# Learning Core Java

This repository contains my **Core Java learning journey** — a collection of practice programs and mini-projects covering Java fundamentals and Object-Oriented Programming (OOP) concepts.

## 📖 What's in this repo?

Each folder inside `src/` covers a specific Java topic, with working code and small practice/console-based projects built to reinforce that concept.

| Folder | What it covers |
|---|---|
| `basics/` | Java syntax fundamentals — variables, data types, basic I/O |
| `operators/` | Arithmetic, relational, and logical operators |
| `conditionals/` | `if-else`, `switch` statements |
| `loops/` | `for`, `while`, `do-while` loops |
| `arrays/` | Array creation, traversal, and manipulation |
| `io/` | Taking user input using `Scanner` |
| `inheritance/` | OOP inheritance — parent/child classes |
| `polymorphism/` | Method overloading and overriding |
| `packages/` & `packagesclient/` | Creating and using custom Java packages |
| `wrapper/` | Wrapper classes (`Integer`, `Double`, etc.) |
| `mathclass/` | Using Java's built-in `Math` class |
| `bank/` | Console-based bank menu app (practice with OOP, getters/setters) |
| `shoppingcart/` | Console-based shopping cart application |
| `smartconsolecalculator/` | Multi-operation calculator with input validation |
| `guessnumbergame/` | Number guessing game using `Random` and loops |
| `madlibsgame/` | Mad Libs style story generator using `Scanner` |
| `practice/` | Extra practice programs (e.g. compound interest calculator) |

## 🎯 Purpose

This repo is not a single project — it's a **learning log**. Every folder represents a topic I studied and practiced hands-on, moving from basic syntax toward small OOP-based console applications, as part of my path to becoming a Java Backend Developer.

## ▶️ How to Run Any Program

1. Navigate into the topic folder you want to run
   ```bash
   cd src/<folder-name>
   ```
2. Compile and run the Java file
   ```bash
   javac FileName.java
   java FileName
   ```
